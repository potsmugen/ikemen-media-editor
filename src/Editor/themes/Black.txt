# Colors are #RRGGBB.
#
# Panel       window, menu bar, and panel backgrounds
# List        list boxes
# Field       input backgrounds (text boxes, number boxes)
# Hover       button hover backgrounds
# Text        primary text

# Separator   the line between panels: splitters and panel borders
# Canvas      backdrop behind sprite pixels
# Accent      filled slider tracks and checkboxes
# Selection   selected table rows
# Active      checked toggle button background
# ActiveText  checked toggle button text
# Variant     Dark or Light; also sets the color of native window chrome
