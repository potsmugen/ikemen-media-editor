# Theme colors for the editor.
#
# Copy this file, give it a new name, and edit the colors to make your own.
# The filename without ".txt" is what appears in Preferences > Theme.
# Anything you save here is used as-is; the app never rewrites your files.
#
# Colors are #RRGGBB.
#
# Panel       panel and tab backgrounds
# Chrome      window, menu bar, project tab strip, status bar, and unselected tabs; a shade apart from Panel
# List        list boxes
# Field       input backgrounds (text boxes, number boxes)
# Hover       button hover backgrounds
# Text        primary text
# Muted       secondary text: labels and table column headers
# Dim         disabled text
# Separator   the line between panels: splitters and panel borders
# Canvas      backdrop behind sprite pixels
# Accent      filled slider tracks and checkboxes
# Selection   selected table rows
# Active      checked toggle button background
# ActiveText  checked toggle button text
# SliderRed, SliderGreen, SliderBlue  filled tracks of the palette R, G and B sliders
# SliderNeutral  filled tracks of the palette H, S, L and A sliders
# Variant     Dark or Light; also sets the color of native window chrome
#
# GitHub's own dark palette (Primer): inset #010409, canvas #0d1117, subtle
# #161b22, border #30363d, fg #e6edf3, muted #8b949e, subtle fg #6e7681.
